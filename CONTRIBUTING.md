# Contributing

VibeCraft.js is enterprise-ready and contributions must follow formal process.

## Requirements

- Open a change ticket and include the ID in your PR.
- Use Conventional Commits.
- Complete the RFC template for material changes.

## Development

- `npm run validate`
- `npm run compliance:pii`

## Approvals

- Two maintainers required.
- Security and Compliance approval if data scope changes.
