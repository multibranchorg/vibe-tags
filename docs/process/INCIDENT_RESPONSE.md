# Incident Response Plan

Enterprise-ready incident response for VibeCraft.js.

## Phases

1. Detect: log anomaly and PII scan triggers.
2. Triage: assign severity and owner.
3. Contain: suspend processing of affected prompts.
4. Eradicate: remove risky artifacts and rotate keys.
5. Recover: validate builds and rerun compliance gates.
6. Review: post-incident RCA and action items.
