# Privacy Notice (Enterprise-Ready Draft)

VibeCraft.js is enterprise-ready and assumes privacy-by-default behavior.

## What We Process

- AI prompts (may contain user-entered content).
- Generated HTML output.
- Build metadata (timestamps, versions, change ticket IDs).

## What We Avoid

- Storing raw PII by default.
- Processing regulated data without explicit approval.

## Controls

- Deny-by-default PII handling.
- Documented data classification policy.
- Mandatory change control for privacy-impacting changes.
