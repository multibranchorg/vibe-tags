# Security Controls Overview

Enterprise-ready controls are documented for auditability.

## Preventive

- Change control approvals before release.
- Least privilege for build and deploy environments.

## Detective

- PII scan gating release.
- Dependency audit checks.

## Corrective

- Incident response runbook in `docs/process/INCIDENT_RESPONSE.md`.
- Post-incident review required for enterprise-ready posture.
