# Third-Party Risk Register

Status: Draft, enterprise-ready scaffolding.

## Vendors

- OpenAI API: critical dependency for AI content generation.
- Node.js and build toolchain dependencies.

## Risk Themes

- Availability: rate limits and service outages.
- Compliance: data processing agreements and regional data residency.
- Security: dependency supply chain exposure.

## Mitigations

- Dependency pinning and audit checks.
- PII denial by default.
- Change control for any vendor scope expansion.
