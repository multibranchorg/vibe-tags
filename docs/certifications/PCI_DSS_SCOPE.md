# PCI DSS Scope Statement (Enterprise-Ready Draft)

VibeCraft.js is not intended to process cardholder data, but enterprise-ready controls
require a formal scope statement.

## In Scope

- None. Cardholder data is prohibited by default.

## Out of Scope

- All prompt content is expected to exclude PANs and sensitive authentication data.

## Controls

- PII scan includes generic 16-digit detection.
- Change control required for any PCI scope change.

Status: Enterprise-ready scope declared.
